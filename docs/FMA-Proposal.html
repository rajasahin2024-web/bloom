1. Executive Summary

Future Meds Academy has already produced a complete, high-fidelity front-end prototype of its learning platform — a public website, a student portal, faculty tools, and a 38-section administration suite covering admissions, academics, fees, exams, and communications.

We propose to rebuild this prototype as a production-grade, scalable web platform — with a real backend, secure authentication, and three new capabilities the academy has requested:

  • Institutional student email IDs — every registered student gets their own @futuremeds.academy-style address, with Gmail-style live availability checking at sign-up.
  • An always-on AI Tutor — a dedicated, independently scalable service trained on the academy's own curriculum.
  • WhatsApp Business API integration — enquiries, enrolment confirmations, class reminders, fee receipts and results delivered on WhatsApp.

3.2 How the platform works

  • Public website + CMS — marketing pages managed by staff from the admin panel.
  • Student portal — enrolment → student record → batches → live & recorded classes → planner → flashcards/quizzes → mocks → progress reports.
  • Admin suite — admissions pipeline, document checklists, attendance, fee ledger with receipts & reminders, email centre, RBAC, analytics.

3.3 Student Email-ID System (requested feature)

At registration the student picks a username; the UI checks availability live — Gmail-style "username taken / available" with suggestions. On confirmation the system provisions a real mailbox, e.g. studentname@futuremeds.academy.

OptionHow it worksCost
A — Google Workspace / Zoho Mail (recommended)API creates a real hosted mailbox; student uses Gmail/Zoho web & mobile apps~₹130–250 per student / month
B — Self-hosted mail serverMail server on the academy's domain (mailcow/Postfix); unlimited mailboxes~₹3–6k / month server + maintenance
C — Platform mailbox (budget)Email-style login ID + in-platform inbox; outbound mail onlyIncluded

Recommended: B for a large student base; A if the academy wants zero mail operations and the full Gmail experience.

3.4 AI Tutor (requested feature — separate, always-on, scalable)

  • A dedicated microservice, isolated from the main app — scales and is billed independently.
  • LLM-powered chat trained on the academy's material via RAG: textbooks, lecture notes, past-paper explanations, error patterns — answers come from FMA's curriculum, not generic internet text.
  • Knows each student's profile: level, target exam, weakest topics, error history (already modelled in the prototype).
  • Horizontally scalable: stateless workers behind a queue, streaming responses, per-student rate limits, usage metering — predictable cost (~₹30–80/student/month typical).
  • Extensible to auto-graded writing/speaking feedback and personalised revision plans.

3.5 WhatsApp Business API (requested feature)

  • Official WhatsApp Business Cloud API — Meta-verified sender, green-tick ready.
  • Automated notifications: enquiry follow-up, admission confirmation, class reminders, fee receipts, mock results, document-checklist nudges.
  • Two-way: student replies land in the admin inbox; optional FAQ chatbot.
  • Template management inside the admin panel.
  • Cost: Meta conversation pricing (~₹0.30–0.80/conversation) or flat-rate reseller plan.

6. Why This Approach

  • The prototype removes the biggest project risk — unclear requirements. Every screen is already decided; we build exactly what the academy designed, on infrastructure that survives real traffic.
  • Modular stack — each piece (AI tutor, WhatsApp, email) turns on per phase without rewrites.
  • Email IDs + AI tutor + WhatsApp are genuine differentiators vs. off-the-shelf LMS products (Teachable / Graphy / Moodle), which offer none of the three natively.

7. Assumptions & Exclusions

  • Content (questions, notes, videos) is provided by the academy; we build the tools to manage it.
  • Domain + Meta/WhatsApp Business verification owned by the academy (we assist).
  • Live classes via integrated provider (Zoom / Google Meet / custom WebRTC — quoted separately if custom).
  • Native mobile apps are a follow-on phase (PWA covers launch).
  • Prices exclude GST.
