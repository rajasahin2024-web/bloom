1. How we will build it

Your existing HTML prototype is the agreed functional spec — every screen, every IELTS module, every admin section is already decided. Our job is to rebuild it on a production-grade, scalable stack (React + FastAPI + PostgreSQL) and add the three requested capabilities: student email IDs on a custom mail server, the Bloom AI Tutor, and WhatsApp automation via WAISE.in.

Delivery runs on two parallel tracks over 3 months:

  • Main track — our application engineer delivers the platform module by module, in the order you asked for: Website → CMS Admin → LMS Admin → Teachers Panel → Student Panel → go-live.
  • AI + infra track — a second engineer owns servers/DevOps, the custom mail server, and builds the Bloom AI Tutor in parallel, so it never delays the main deliveries.

Every milestone ends with a live demo + acceptance checkpoint. You see working software every stage — not just at the end.

3. Milestone details

Milestone 0 · Week 1 · Foundation

Foundation & environment setup

  • Cloud VPS, database (PostgreSQL), cache/queue (Redis), and deployment pipeline set up
  • Secure login foundation (JWT + OTP, roles: student / teacher / admin)
  • Staging environment live — you can watch progress on a private preview URL throughout the project
  • Interface contracts frozen between the platform, the AI Tutor and WAISE.in — so all tracks build independently without blocking each other

Checkpoint: staging environment live. Payment: Booking advance — ₹50,000

Needed from Bloom this week: domain/DNS access, VPS purchase approval, WAISE.in Professional subscription activated, Razorpay/Cashfree merchant KYC started, first batch of curriculum content for the AI knowledge base.
Milestone 1 · Weeks 2–4 · Month 1 delivery

Public Website + CMS — website goes live

  • All public pages rebuilt and live on your real domain: Home, About, Courses & Pricing, IELTS, Medical/OET, Study Abroad, Blog, Results, Careers, Contact, Login
  • Full SEO plumbing carried over: sitemap, structured data (JSON-LD), social cards, PWA manifest
  • Enquiry & careers forms → admin inbox → instant WhatsApp alert via WAISE.in
  • Staff CMS: your team edits all website content, blog posts, results and media without a developer

Checkpoint: live website demo + your acceptance. Payment: Month 1 delivery — ₹55,000

Milestone 2 · Weeks 5–8 · Month 2 delivery

Unified Admin Panel + student email system

  • One operations suite for staff: admissions & student records, fees / receipts / subscriptions / reminders, communications, academic setup, personnel & HR documents, operations, analytics, exam-track assignment — with the website CMS merged into the same panel
  • Custom mail server built on a dedicated VPS (Postfix + Dovecot + Rspamd + SOGo): full SPF/DKIM/DMARC/PTR mail authentication so academy email lands in inboxes
  • Mailbox provisioning API connected to the platform — the foundation for student @bloomielts.com email IDs at registration
  • Admin mailbox controls: suspend, reset password, storage quota per student

Checkpoint: admin suite demo + email-ID provisioning demo. Payment: Month 2 delivery — ₹85,000 (includes one-time mail-server setup)

Milestone 3 · Weeks 6–9

Teachers Panel

  • Teaching planner and class roster
  • Live teaching console for running classes
  • Content manager — teachers upload material to the library
  • Exam builder — faculty authors passages, sections and question sets

Checkpoint: teachers panel demo with your faculty.

Milestone 4 · Weeks 7–11 · Month 3 delivery

Student Panel — the full learning experience

  • Registration with live email-ID availability check — Gmail-style "taken / available" — then a real studentname@bloomielts.com mailbox is created automatically
  • Placement test + CEFR level, personalised dashboard, weakest-module detection
  • Every IELTS skill lab: Listening Part 1–4, Reading (Academic + GT), Writing Task 1–2, Speaking Part 1–3, Grammar & Vocabulary, Exam Strategy
  • Mock exams with band-score reporting; multi-exam tracks (IELTS A/G, TOEFL, PTE, Duolingo, Cambridge, OET) assigned by staff
  • Study planner, library, live classes & schedule, 1-on-1 tutoring booking, progress & English Profile
  • Fee payment online (Razorpay/Cashfree — UPI, cards, EMI)

Checkpoint: full student journey demo — register → email ID → placement → practice → mock → band report.

Milestone 5 · Weeks 11–12 · Go-live

Integration, hardening & launch

  • Bloom AI Tutor integrated into the student portal
  • Full WhatsApp notification set live: enquiry follow-up, admission confirmation, class reminders, fee receipts, results
  • Load testing (exam-day traffic), security review, daily automated backups + restore drill
  • Your team's acceptance testing, final fixes, production launch, staff handover training

Checkpoint: go-live + handover. Payment: Month 3 delivery — ₹60,000

Parallel track · Weeks 1–12

Bloom AI Tutor (dedicated engineer)

  • Month 1: service skeleton — AI gateway, worker, knowledge-base pipeline, first embeddings of Bloom curriculum
  • Month 2: answer-quality pass on your material, student-profile awareness, tutor personas & guardrails, evaluation checks
  • Month 3: hardening + usage metering, integrated into the Student Panel, live with the platform

The tutor answers only from Bloom's own curriculum — not generic internet text — and adapts to each student's level and weak modules.

6. How we keep it on time

  • Weekly progress demos — you see working software every week on the staging environment, not just at month-ends.
  • Milestone acceptance checkpoints — each stage closes only after your demo sign-off; payments map to accepted deliveries.
  • Prototype = spec — no discovery phase, no re-design debates; the build starts on day one.
  • Frozen interface contracts — the AI Tutor and WhatsApp work proceed in parallel without blocking the platform.
  • Single point of contact — one architect/PM answers for schedule, scope and quality.
  • Scope control — anything beyond the prototype's agreed scope is quoted as a change request, so the timeline is never silently stretched.
Bottom line: 6 milestones, 3 months, demo + acceptance at every stage. The website is live from Month 1, the operations suite and student email IDs from Month 2, and the complete student experience — with the AI Tutor and WhatsApp automation — goes live at the end of Month 3.
